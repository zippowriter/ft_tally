# ブラウザビューアのテストリスト

[課題文](../../ft_tally.md) の Chapter III と IV.5 に基づく。実ブラウザでファイル選択、条件変更、表の操作を検証する。

## 課題の要件

1. [x] ES モジュールを読み込み、CSV のファイル入力を有効にする。読み込み前の条件は無効にする。
2. [x] ファイルを選択すると、CSV のヘッダーからグループ化列と集計列を作る。
3. [x] 選択した CSV を型推論し、ヘッダーと行を表に表示する。
4. [x] グループ化列の変更でページを再読み込みせずに表を更新する。
5. [x] 集計方法と集計列の変更を表に反映し、件数・合計・平均・最小・最大を選べる。
6. [x] 表の見出しをクリックすると昇順・降順を切り替える。再描画後の見出しも同じ表に付けた1つのリスナーで操作できる。
7. [x] HTML に見えるヘッダーとセルの値を文字として表示する。
8. [x] 不正な CSV は行番号を含むエラーをページ上に表示し、未捕捉例外を出さない。
9. [x] 数値列でない列を数値集計に選んだ場合はエラーを表示し、条件を修正すると表示を復旧する。

## 課題文に明記されていない動作

10. [x] ヘッダーだけの CSV でも列を選択でき、表の見出しを表示する。
11. [x] 別の CSV を選択すると前の条件・並び順・表を新しいファイルの内容に置き換える。
12. [x] ファイルの読込失敗をページ上に表示し、次に有効なファイルを選ぶと復旧する。
13. [x] 読み込み中に別のファイルを選択すると、最後に選択したファイルの結果を保つ。
14. [x] グループ列名と集計名が重なる場合も両方の列を表示する。
