# `parseCsv` のテストリスト

[課題文](../../ft_tally.md) の IV.1 に基づく。上から順にテストを1件ずつ書き、各ステップで確認を受ける。完了した項目にはチェックを入れる。

1. [x] LF 区切りの CSV から `header` と `rows` を返し、`001` や `false` を文字列として保持する。
2. [ ] CRLF 区切りの CSV を読み取れる。
3. [ ] 引用符で囲んだヘッダー名にカンマを含められる。
4. [ ] 引用符付きのセルにカンマを含められる。
5. [ ] 引用符付きのセルに改行を含められる。
6. [ ] 引用符付きのセル内の `""` を1つの `"` として読み取る。
7. [ ] 行末の空セルを `''` として保持する。
8. [ ] ファイル末尾の改行で余分なレコードを作らない。
9. [ ] 引用符を閉じずにファイル末尾に達すると、該当レコードの開始行を含むエラーになる。
10. [ ] 列が足りない行で、該当レコードの開始行を含むエラーになる。
11. [ ] 列が多い行で、該当レコードの開始行を含むエラーになる。
12. [ ] 2〜3行目にまたがる正常なレコードの直後でエラーが起きたとき、4行目を報告する。

エラーの行番号は、ファイルの先頭を1行目とし、該当レコードが始まる物理行で数える。空ファイルと文字列以外の入力の扱いは、課題仕様に明記されていない。
