# CLI のテストリスト

[課題文](../../ft_tally.md) の Chapter III と IV.4 に基づく。
実際の CLI を子プロセスとして実行し、標準出力、標準エラー出力、終了コードを確認する。

## 課題の要件

1. [x] 指定した CSV を読み込み、既定で列幅を揃えた表を出力する。
2. [x] `--format json` は数値・真偽値・欠損値を型推論し、整形済み JSON を出力する。
3. [x] `--where` は型推論後の値で比較し、複数の条件をすべて満たす行だけを返す。
4. [x] `--group-by` と `--count` はグループごとの件数を返す。
5. [x] `--sum` は `sum_列名` に非欠損値の合計を返す。
6. [x] `--avg` は `avg_列名` に非欠損値の平均を返す。
7. [x] `--min` は `min_列名` に非欠損値の最小値を返す。
8. [x] `--max` は `max_列名` に非欠損値の最大値を返す。
9. [x] `--sort` は入力列で昇順・降順に並べ替える。
10. [x] `--limit` は並べ替え後の行を指定件数に絞り、0件も扱う。
11. [x] 課題文の使用例のとおり、グループ化・集計・集計列での降順・上位抽出を組み合わせられる。
12. [x] ファイル指定がなければ、標準エラー出力にメッセージを出し終了コード1で終了する。
13. [x] 存在しないファイルを指定した場合も標準エラー出力と終了コード1で伝える。
14. [x] 不正な CSV は、行番号を含むメッセージと終了コード1で伝える。
15. [x] 未知のオプションと余分な位置引数を拒否する。
16. [x] 値を必要とするオプションの直後が引数末尾や別のオプションなら拒否する。
17. [x] 認識できない出力形式を拒否する。
18. [x] `=` がない、または列名がない `--where` を拒否する。
19. [x] 列名と方向のいずれかがない、または方向が不正な `--sort` を拒否する。
20. [x] 負数、小数、指数表記、安全な整数の範囲外の件数を拒否する。
21. [x] 入力ヘッダーにない絞り込み列・グループ列・集計元列を、データ行がなくても拒否する。
22. [x] 結果に存在しない並べ替え列は、絞り込み結果が0行でも拒否する。
23. [x] 数値列でない列の数値集計は、列名を含むエラーとして伝える。

## 課題文に明記されていない動作

24. [x] `--where col=` は欠損値に一致し、比較値の2個目以降の `=` は値の一部として扱う。
25. [x] 空の結果を表で出力するとヘッダーだけを表示し、`--format table` は既定と同じ形式を使う。
26. [x] 日本語の全角文字を含む表で列を揃え、改行・タブなどの制御文字はエスケープして1レコードを1行で表示する。
27. [ ] 集計名がグループ列と重なる場合は集計名に連番を付け、両方の列を保持する。
