# クエリのテストリスト

[課題文](../../ft_tally.md) の IV.2〜IV.4 に基づく。`createQuery` は型推論済みの行を受け取る。上から順に1件ずつ検証する。

## 課題の要件

1. [x] 条件のない `run()` は入力と同じ内容の行を入力順に返す。
2. [x] `where` は述語を満たす行だけを返す。
3. [x] 同じクエリから分岐した `where` は独立し、連続した `where` はすべての条件を適用して新しいクエリを返す。
4. [x] `groupBy` と `aggregate` はグループ列と指定した集計名を持つ行を返し、`count` はグループごとの行数を数える。
5. [x] `sum` は `null` を除外して数値を合計する。
6. [x] `avg` は非欠損値の件数で合計を割る。
7. [x] `min` は `null` を除外して最小値を返す。
8. [x] `max` は `null` を除外して最大値を返す。
9. [x] 数値以外の値を含む列への数値集計は、列名を含むエラーになる。列の型は絞り込み前の入力全体で判定する。
10. [x] `sortBy` は数値を昇順・降順で並べ替え、入力と親クエリを変更しない。
11. [x] `limit` は先頭から指定件数を返し、0件や入力件数を超える上限も扱う。
12. [x] CSV を型推論し、絞り込み・グループ集計・集計列の並べ替え・件数制限を順に実行できる。

## 課題文に明記されていない動作

13. [x] `groupBy` 単独ではグループ列の値を初出順に1回ずつ返す。`null` もグループキーになり、数値と同じ表記の文字列は別のキーになる。
14. [x] `groupBy` を指定しない集計は全行を対象として1行返す。`["count"]` は行数を数えるので、集計対象のセルが欠損していてもその行を含める。
15. [ ] 数値が0件の集計は `sum` と `count` をそれぞれ合計の初期値と行数で返し、`avg`・`min`・`max` を `null` で返す。空入力のグループ集計は0行になる。
16. [ ] 入力や集計指定を後で変更しても、組み立て済みのクエリは保持した値を使う。述語や戻り値を通じた行の変更も入力や別の実行に波及しない。
17. [ ] 方向を省略した並べ替えは昇順にする。文字列を並べ替え、同値の行は元の順序を保ち、`null` は両方向で末尾に置く。
18. [ ] 不正な集計関数・並べ替え方向・件数制限はエラーになる。入力に行があり集計対象の列が存在しない場合は、列名を含むエラーになる。
